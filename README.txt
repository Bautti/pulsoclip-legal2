PulsoClip — Pack estatico para GitHub Pages (verificacion TikTok Production)
=========================================================================

Archivos incluidos:
- .nojekyll         -> evita que GitHub Pages oculte o altere archivos estaticos
- index.html        -> pagina principal informativa (Website URL)
- terminos.html     -> Terminos de Servicio en espanol (Terms of Service URL)
- privacidad.html   -> Politica de Privacidad en espanol (Privacy Policy URL)
- logo-1024.png     -> logotipo 1024x1024 PNG requerido por TikTok

Pasos rapidos:
1. Crea un repositorio PUBLICO en GitHub (ej. pulsoclip-legal).
2. Sube estos archivos a la raiz del repositorio.
3. Activa Settings -> Pages -> Deploy from a branch -> main / (root).
4. Cuando TikTok te pida "Verify URL -> URL prefix", descarga el archivo
   tiktok*.txt que te entrega TikTok y subelo tambien a la raiz de este repo.
